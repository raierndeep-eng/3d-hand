# 3d-hand

This repository contains two separate things:

- **`index.html`**: a mobile 3D hand tracker (MediaPipe and Three.js).
- **`gob/`**: **GOB**, a story-driven 3D browser game. See [`gob/README.md`](gob/README.md) for how to run and play it.

Quick start for GOB:

```bash
cd gob
python3 -m http.server 8000
# then open http://localhost:8000
```
